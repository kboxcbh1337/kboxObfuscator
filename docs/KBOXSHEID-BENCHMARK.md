# kboXShield 保护效果基准协议

> 适用版本：3.0.4 ｜ 更新：2026-10-23

本文件定义**可被第三方复现**的对比实验，用于回答"kboXShield 的逆向阻力到底如何"。
在没有完成本协议前，发布说明不得给出"强于某商业壳"的结论。

---

## 1. 样本集（固定、可公开）

| 编号 | 类型 | 特征 | 来源 |
|---|---|---|---|
| S1 | 小 DLL | 2~5 个具名导出，纯算术 | 本仓库 `samples/shield/`（MIT 许可） |
| S2 | 中 DLL | 字符串表 + 分支逻辑 + 导出枚举 | 待补 |
| S3 | 大 DLL | 多模块、含 C++ 异常 | 待补 |
| S4 | EXE | 控制台程序，含命令行解析 | 待补 |

> 样本与产物必须可公开下载；不能只给截图或结论。

## 2. 冻结的对照版本

| 产品 | 版本 | 备注 |
|---|---|---|
| kboXShield | 3.0.4 | 本仓库 tag `v3.0.4` |
| 对照 A | 记录具体版本 | 商业壳需说明授权与配置 |
| 对照 B | 记录具体版本 | 例如 VMProtect / Themida 的默认与最高档各一组 |

每个产品的**参数、档位、编译选项**必须完整记录；"最高档"与"默认档"不能混为一谈。

## 3. 环境

- 操作系统版本（`winver`）、CPU、内存；
- 反病毒/EDR 状态（开启/关闭），因为已知会改变加载成功率；
- 分析工具及版本：IDA/Ghidra/x64dbg/CFR 等；
- 记录网络是否隔离（避免样本外泄争议）。

## 4. 指标

| 指标 | 定义 |
|---|---|
| 加载成功率 | 成功 `LoadLibrary`/启动次数 ÷ 总次数 |
| 导出可用率 | `GetProcAddress` 成功的导出数 ÷ 导出总数 |
| 首次定位时间 | 从打开样本到定位目标函数的时间（人类计时） |
| 语义恢复率 | 可被正确还原的规则/阈值比例（需预先标注 ground truth） |
| 自动化成功率 | 固定时间预算内，脚本/符号执行恢复目标的比例 |
| 体积/性能开销 | 文件大小比、启动时延、导出调用时延 |
| 已知失败数 | 崩溃、无响应、加载失败、AV 拦截 |

## 5. 执行步骤（每次重复 3 次）

1. 用固定 seed 构建 kboXShield 产物；记录 SHA-256 与 `srox-report.json`。
2. 对每个样本运行加载/导出矩阵（`--shield-matrix` + 宿主测试程序）。
3. 分析者在不知道产物来源的情况下（盲测）执行定位与还原任务。
4. 记录结果与失败案例；失败必须保留，不允许只报成功。
5. 汇总为 `benchmark-<date>.md` 并随版本发布。

## 6. 复测与评审

- 邀请**未参与开发**的逆向工程师复测，至少在两个独立环境执行；
- 提供完整命令、参数、环境与原始日志；
- 若复测结论与作者结论冲突，以复测为准并公开修订。

## 7. 现状

- 3.0.4 仅完成"构建期导出表校验 + 单样本矩阵"；
- 人工语义恢复率、自动化成功率与对照产品对比：**未完成**；
- 因此当前**没有任何强度领先的公开结论**。
